**FIGMA DESIGN BRIEF — SPARK Brand Genesis (full premium pass)**  
*Story-format · Super Spark–directed · no steps removed · all platforms listed*

---

### Concept (push it)

Not a wizard. Not a chat app.  
A **full-bleed executive story** directed by Super Spark: cinematic dark stage, story progress segments, one decision per frame, **typing director lines**, rich visual choices (platform logos, genre art), and a living reply field so the executive can always ask.

**Mood:** Apple product film × CapCut mobile power × Spotify personality × quiet SPARK intelligence.  
**Motion:** Story advances; Super Spark *types*; selections *settle* with soft scale/glow—not gimmicky confetti.

**Rules**
- Super Spark copy appears with **typewriter / staggered reveal**, then holds.
- Helper line always present under canvas: *Don’t know what to do? Feel free to ask me. I’m Super Spark.*
- Text field always available (ask or custom input)—secondary to canvas, not a message thread.
- **No** logo inside a round chat bubble.
- Sticky primary CTA + safe area on mobile.
- Desktop: same IA, centered story column ~440px, ambient purple/cyan glow behind stage.

### Frame 0 — Entry

**Typing:**  
“Welcome. I’m **Super Spark**, your executive creative director. Let’s build the brand SPARK will run.”

**Canvas:** Quiet mark + soft orb glow.  
**Primary:** Begin  
**Micro:** Don’t know what to do? Feel free to ask me. I’m Super Spark.

---

### Frame 1 — Connect accounts *(all platforms)*

**Typing:**  
“Connect the social accounts you want SPARK to manage.  
I’ll use them for identity, publishing, and distribution.  
Don’t know what to do? Feel free to ask me. I’m Super Spark.”

**Canvas — platform grid (logos mandatory)**  
List **all** product platforms, including not-yet-live. Do not hide unconfigured ones.

| Platform | Logo treatment | State if not live |
|----------|----------------|-------------------|
| YouTube | Official color mark | Connect |
| YouTube Shorts | YouTube mark + Shorts cue | Connect (or same Google OAuth) |
| X (Twitter) | X mark | Connect |
| Instagram | IG glyph / gradient mark | Connect or **Soon** badge |
| TikTok | TikTok mark | Connect or **Soon** |
| Facebook | FB mark | Connect or **Soon** |
| LinkedIn | in mark | Connect or **Soon** |
| Threads | Threads mark | Connect or **Soon** |
| Pinterest | Pinterest mark | Connect or **Soon** if in product list |
| Snapchat | Ghost mark | **Soon** if listed |

**Card anatomy**
- Platform logo (correct brand asset, not generic icons)
- Name
- State pill: Connect · Connecting… · Connected @handle · Soon · Error
- Connected: avatar + handle strip

**Soon cards:** full logo, muted, non-blocking, label “Available soon”—still visible so the system feels complete.

**Skip:** text link “Continue without connecting”  
**Timeout:** Connecting max ~10s → Error + Retry  
**Primary:** Continue  

**Text field:** “Which account should SPARK manage first?” / free ask

### Frame 2 — Brand + Niche

**Typing:**  
“What should we call this brand—and what niche does SPARK own?”

**Canvas**
- Brand / channel name (prefilled from connected account when possible)
- Niche chip cloud (rich, scroll-wrap): AI · Business · Finance · Fitness · Fashion · Beauty · Comedy · Education · Tech · Crypto · Lifestyle · Food · Gaming · Motivation · News · Other…
- Optional row: Goal chips (Growth · Authority · Sales · Community)

**Primary:** Continue

### Frame 3 — Character *(visual genre category)*

**Typing:**  
“Who is the host on camera? Lock a character SPARK can keep consistent forever.”

**Canvas A — Genre category grid (image tiles, not text-only)**  
Each tile = **representative still**, label under or on hover/press:

| Category | Image direction |
|----------|-----------------|
| Human / Realistic | Photoreal person, neutral studio |
| Cinematic | Film-light portrait, shallow DOF |
| 3D | Stylized 3D character render |
| Anime | Clean anime character key art |
| Cartoon | Bold cartoon character |
| Illustration | Editorial illustrated figure |
| Comic | Comic-panel character |
| Art / Stylized | Painterly / fine-art figure |
| Clay / Stop-motion | Clay-figure look |
| Pixel | Pixel-art character |

Selected tile: strong border + soft glow. Large enough to *feel* the medium.

**Canvas B — Specs (after genre or same scroll)**  
Chip rows: Skin · Hair · Wardrobe · Personality  
Short notes field  

**Canvas C — Generate**
- Primary in-canvas: **Generate character sheet**
- Result: large multi-panel sheet preview (front / side / attitude—not a tiny avatar)
- Tap sheet → **fullscreen story viewer** (swipe to dismiss / X)
- Regenerate · Upload reference  

**Primary:** Continue when satisfied  

---

### Frame 4 — Voice

**Typing:**  
“Choose the narrator voice for your content. This is your brand voice—not my chat voice.”

**Canvas**
- Voice list: waveform or avatar-neutral row · **Play** · **Select**
- Male / Female / Neutral filters if available
- Block: **Design a voice** — type description → generating → preview cards with Play · Use this

**Text field:** “Describe the voice you want…”  

**Primary:** Continue  

---

### Frame 5 — Research Sources

**Typing:**  
“Paste channels or profiles SPARK should learn from. I’ll start analyzing as soon as you add them.”

**Canvas**
- URL field + Add  
- Source chips with platform mini-logo when detectable  
- Status: Syncing… · Ready · Couldn’t sync  

**Distinct from Frame 1:** these are **inspiration / research**, not “accounts SPARK manages.”  

**Primary:** Continue · Skip as text  

---

### Frame 6 — Modes

**Typing:**  
“How should SPARK produce—and how much should I decide without you?”

**Canvas — two cinematic choice groups**

**Production**
- **Narrator** — voice + visuals, lean  
- **Hybrid** — stronger motion + host  
- **Cinematic** — full storyboard / filmic depth  

**Automation**
- **Manual** — you approve  
- **Balanced** — SPARK drafts, you gate strategy  
- **Autonomous** — SPARK runs within brand rules  

Each option: short subtitle, selected = filled card.

**Primary:** Continue  

---

### Frame 7 — Ready

**Typing:**  
“Your SPARK is ready. Enter when you are.”

**Canvas — premium summary strip**
- Brand + niche  
- Character sheet thumb → fullscreen  
- Voice name  
- Connected accounts (logos)  
- Research count  
- Modes  

**Primary (immovable sticky):** **Enter SPARK Dashboard**  

No CTA buried under scroll.

### Super Spark behavior (design this explicitly)

| Moment | Behavior |
|--------|----------|
| Enter frame | Cursor blink → type line → hold |
| User idle | Soft second line: “Don’t know what to do? Feel free to ask me. I’m Super Spark.” |
| User sends text | Brief “thinking” pulse on mark → short answer card (not full chat history) |
| Error | Typed honesty: “That connection didn’t complete. Retry or skip—I’ll still build your brand.” |
| After generate | “If this isn’t the host, regenerate. When it feels right, continue.” |

Answers stay **short cards**, not a scrolling messenger.

### Visual system (don’t hold back)

- **Depth:** layered vignette, one soft purple bloom, one cool bloom—story stage floats  
- **Typography:** Bold director line; quieter helper; CTA label decisive  
- **Genre tiles:** real artwork mockups (not gray boxes)—this frame should feel like choosing a universe  
- **Platform tiles:** official logo colors on dark glass cards  
- **Character fullscreen:** black surround, sheet centered, close control obvious  
- **Sound design note for prototype (optional):** soft tick on segment advance; no loud UI noise  
- **Haptics note (mobile):** light impact on select
